# Chula Pat14 living room and kitchen

The named MuJoCo world `chula_pat14_6` of the `walkie_mujoco_worlds` package: a
reconstruction of the living room and kitchen of
[map collection `30_16102026_ChulaPat14_6`](https://github.com/EIC-Robocup-2026/map-collection/tree/main/30_16102026_ChulaPat14_6),
with its occupancy map, in two variants (`lowpoly` and `baked`).

[Chula Pat14 Room Simulation](../../../../docs/guides/simulation-chula-pat14.md)
documents this world:

- how to run it with AMCL and Nav2, and how to choose the variant and the spawn
- what each file in this directory is, and which files the package installs
- how to edit and export it in Blender, and how to verify an export

The format of `world.toml` and the rules for an exported scene are in
[MuJoCo Simulation: Add a named world](../../../../docs/guides/simulation-mujoco.md#add-a-named-world).
